Agricultural Finance & Capital

How capital enters the agricultural graph — from a producer's need to a lender's balance sheet, and back.

Overview

Capital is the edge that has to exist before most physical activity in the agricultural graph can happen: a farmer needs financing for equipment, land, or an operating season before production, storage, or transportation ever occur. This system deep dive traces that lifecycle through a Farm Credit System lender, using Farm Credit Southeast Missouri's real public disclosures as the concrete example — see /organizations/farm-credit-southeast-missouri.

Pipeline

  1. 1. Capital Need Identified

    A producer needs financing for operating expenses, equipment, land, or insurance ahead of a production season.

  2. 2. Application & Financial Intake

    Farm financials, production history, and collateral information are submitted — typically through a CRM/origination system such as Salesforce or nCino.

  3. 3. Underwriting & Credit Analysis

    The lender evaluates capacity, capital, collateral, character, and conditions (the classic '5 Cs') against enterprise data sources.

  4. 4. Approval & Loan Structuring

    Terms, rate, amortization, and (for a cooperative lender) patronage eligibility are set and the loan closes.

  5. 5. Servicing, Monitoring & Reporting

    Payments post through a loan-accounting system (e.g. FIS Profile); portfolio-level dashboards (e.g. Power BI) track concentration, delinquency, and renewal risk.

The Four Pillars, Applied

Business Analysis

Map the handoffs between loan officer, underwriting, closing, and servicing — the classic place to find duplicate data entry across Salesforce, nCino, and a core loan-accounting system.

Data Intelligence

A relational data model (producer, loan, collateral, payment) feeding KPIs like days-to-decision, portfolio concentration by commodity, and delinquency rate, surfaced in Power BI.

Systems Mapping

The Capital Graph: lender/insurer/public funding → operator → asset/operation → production → revenue → repayment, cross-linked to the region's Physical Graph (what that capital actually buys).

AI & Automation

Approved generative AI for research, document summarization, and drafting — used on the lender's own approved tools, with confidential borrower information never leaving the system it belongs in.

Illustrative Data Model

An illustrative schema for the Capital Graph — not Farm Credit Southeast Missouri's actual production schema, which is private.

CREATE TABLE producer (
  producer_id      INT PRIMARY KEY,
  county            VARCHAR(64),
  primary_commodity VARCHAR(64)
);

CREATE TABLE loan (
  loan_id       INT PRIMARY KEY,
  producer_id   INT REFERENCES producer(producer_id),
  loan_type     VARCHAR(32), -- real_estate | operating | equipment
  amount        DECIMAL(14,2),
  origination_date DATE,
  status        VARCHAR(24)
);

CREATE TABLE collateral (
  collateral_id INT PRIMARY KEY,
  loan_id       INT REFERENCES loan(loan_id),
  asset_type    VARCHAR(32), -- land | equipment | crop
  appraised_value DECIMAL(14,2)
);

CREATE TABLE payment (
  payment_id    INT PRIMARY KEY,
  loan_id       INT REFERENCES loan(loan_id),
  due_date      DATE,
  paid_date     DATE,
  amount        DECIMAL(14,2)
);
