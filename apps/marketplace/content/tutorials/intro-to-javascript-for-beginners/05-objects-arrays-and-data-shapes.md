# Objects, Arrays, and Data Shapes

`Memory`, room objects, and creep bodies are all just objects and arrays under the hood. This lesson covers shaping and reading that kind of data, which is most of what colony code actually does.

This lesson is coming soon. Planned outline:

- Object literals: keys, values, and nested objects (like `Memory.creeps.Harvester1.role`)
- Arrays: indexing, `.length`, and the array methods you'll use constantly (`find`, `filter`, `map`)
- Destructuring to pull values out of objects and arrays cleanly
- Designing a `Memory` shape that stays readable as a colony grows
