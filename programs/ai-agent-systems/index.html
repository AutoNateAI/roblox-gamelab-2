Get the Course arrow_forward
Week 01

Meet your AI agents

Set up Claude Code and Codex, and practice engineering prompts and context for real projects.

01Meet Your AI Agents

Set up Claude Code and Codex as real collaborators and learn to point an agent at an unfamiliar codebase before asking it to change anything.

Live: Install and configure Claude Code and Codex, walk through a real repository together, and have an agent explain its architecture, entry points, and data flow back to you.Homework: Use an agent to map a small existing codebase and write a short architecture note describing its components and how they connect.
02Prompt and Context Engineering in Practice

Apply prompt and context engineering to a real multi-file project: structure the ask, and give the agent only the context it actually needs.

Live: Take a real feature request, structure a prompt with role, task, and constraints, hand the agent the relevant files, and review the diff line by line.Homework: Use an agent to implement one small feature in an existing project and document what context you gave it, what you accepted, and what you rejected.
Week 02

Databases, APIs, and architecture

Design relational and graph data models, build APIs, and document the system with Mermaid diagrams.

03Databases and APIs

Design a relational schema for a real problem, wire up a simple API, and use an agent to scaffold both responsibly.

Live: Design tables, keys, and relationships for a sample system, build API endpoints against them, and query the data live.Homework: Add one table and one API endpoint to a project, and write the query that answers a real question about the data.
04System Architecture and Mermaid Diagrams

Turn a working system into a diagram: use Mermaid to communicate architecture and organize services and components.

Live: Pick a real system, diagram it in Mermaid, identify its weak points, and talk through tradeoffs with an agent.Homework: Produce a Mermaid architecture diagram for your own project and one paragraph explaining a tradeoff you made.
Week 03

Review, debug, and research

Review AI-generated code like an engineer, then find and read a real RFP with an agent's help.

05Debugging and Reviewing AI-Generated Code

Build the habit of reviewing agent output like a senior engineer: reading diffs, running tests, and catching hallucinated logic.

Live: Review a batch of AI-generated changes live, find at least one real bug or hallucination, fix it, and commit the working version.Homework: Review and correct one AI-generated change in your own project, documenting what was wrong and why.
06Reading a Real RFP With AI

Find and read an actual government or foundation RFP, and use an agent to extract requirements, stakeholders, and constraints.

Live: Pull a live RFP, have an agent summarize it, and identify who issued it and what problem it's really asking to solve.Homework: Find one real RFP or civic problem and write an agent-assisted summary of what it's asking for and who it would help.
Week 04

Build week

Turn the researched RFP into a real system design, build it live, and ship it for a real organization.

07Build Week Part 1 - Design and Start the Real System

Turn the researched RFP into an actual system design and start building it live.

Live: Design the architecture for the chosen system, scaffold the repository, and implement the first real feature with agent support.Homework: Keep building: commit progress and update the architecture notes as the design changes.
08Build Week Part 2 - Ship It

Finish a working version of the system, write it up, and identify who to contact about it.

Live: Finish the build, demo it live, and draft outreach identifying the people or organization who should see it.Homework: Submit final repo link, architecture notes, a short system writeup, and the outreach draft.
